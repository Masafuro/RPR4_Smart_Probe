# RPR4 Smart Probe 拡張仕様と基板設計仕様（65×33mm / 24P THT）

## 1. 状況と経緯
RPR4は当初、ADXエコシステムにおけるLN-485やスケッチ書き込み専用ドングルとして構想されたが、汎用RS-485スマートプローブとして独立したプロジェクト（`RPR4_Smart_Probe`）へ昇華した。

基板外形を **65mm × 33mm**（Raspberry Pi Zeroやフリスクケースに近い、片手でしっかり握れる黄金比）に決定したことで、十分な絶縁沿面距離と配線スペースを確保すると同時に、**片側12P × 2列（合計24P、2.54mmピッチ）** の広大な拡張THTスルーホールを左右に配置可能となった。

これにより、PCやスマホに接続する「超薄型USBドングル」としての基本機能に加え、**「液晶画面＋LiPoバッテリー＋操作キー＋microSDを搭載したスタックシールド」を載せることで、完全自立型のポケットRS-485フィールドテスター** へと容易にトランスフォームできる構造が確立された。

---

## 2. 基板外形および拡張端子仕様

- **基板外形**: **65.0mm × 33.0mm**
- **先端部**: SMDスプリングクランプ端子台（HDGC4001SMD-S-2P、4mmピッチ、工具レス）
- **後端部**: USB 2.0 Type-C コネクタ
- **拡張端子 (THT)**: 2.54mmピッチ 12P × 2列（合計24ピン、WeMos D1 Mini スタイル拡張）

```text
              【 USB Type-C コネクタ側 】
                    ┌───────────┐
                    │  RP2040   │
                    │  & FLASH  │
     (J1: 左列)     │           │     (J2: 右列)
  1  3V3            │ [ ]   [ ] │ 13  5V (VBUS)
  2  GND            │ [ ]   [ ] │ 14  GND
  3  RESET (RUN)    │ [ ]   [ ] │ 15  BOOT (BOOTSEL)
  4  GP4 (I2C0_SDA) │ [ ]   [ ] │ 16  GP8 (UART1_TX)
  5  GP5 (I2C0_SCL) │ [ ]   [ ] │ 17  GP9 (UART1_RX)
  6  GP16(SPI0_RX)  │ [ ]   [ ] │ 18  GP20(KEY1 / UP)
  7  GP17(SPI0_CSn) │ [ ]   [ ] │ 19  GP21(KEY2 / DOWN)
  8  GP18(SPI0_SCK) │ [ ]   [ ] │ 20  GP22(KEY3 / ENTER)
  9  GP19(SPI0_TX)  │ [ ]   [ ] │ 21  SWCLK (SWDデバッグ)
 10  GP26(ADC0)     │ [ ]   [ ] │ 22  SWDIO (SWDデバッグ)
 11  GP27(ADC1)     │ [ ]   [ ] │ 23  GP0 (RS485_DI / TXモニタ)
 12  GP28(ADC2)     │ [ ]   [ ] │ 24  GP1 (RS485_RO / RXモニタ)
                    │           │
                    │ [TDA51S]  │
                    └───────────┘
              【 RS-485 スプリング端子台 】
```

## 3. 24P ピンアサイン詳細仕様

### ■ 左列 (J1: 1〜12番ピン)
| Pin | 信号名 | RP2040機能 | 主な用途・拡張シールドでの役割 |
| :---: | :--- | :--- | :--- |
| **1** | **3V3** | 電源出力 | オンボード 3.3V LDO 出力（センサー・OLED・SDカード給電） |
| **2** | **GND** | 電源グラウンド | デジタル基準グラウンド |
| **3** | **RESET** | `RUN` | ハードウェアリセット（GNDショートでリセット） |
| **4** | **GP4** | `I2C0_SDA` / GPIO4 | 0.96"〜1.3" OLEDディスプレイ直結 / I2Cセンサー |
| **5** | **GP5** | `I2C0_SCL` / GPIO5 | OLEDディスプレイクロック / I2C環境・電流センサー |
| **6** | **GP16** | `SPI0_RX` (MISO) / GPIO16 | microSDカードシールド / 外部高速通信 |
| **7** | **GP17** | `SPI0_CSn` / GPIO17 | microSDカード チップセレクト (CS) |
| **8** | **GP18** | `SPI0_SCK` / GPIO18 | SPI クロックライン |
| **9** | **GP19** | `SPI0_TX` (MOSI) / GPIO19 | microSDカードへのパケットログ連続記録 |
| **10** | **GP26** | `ADC0` / GPIO26 | 現場電圧測定（0〜3.3V、または分圧で0〜24V計測） |
| **11** | **GP27** | `ADC1` / GPIO27 | 電流（4-20mAシャント）測定 / 外部アナログプローブ |
| **12** | **GP28** | `ADC2` / GPIO28 | 拡張シールド側 LiPoバッテリー電圧監視（残量計） |

### ■ 右列 (J2: 13〜24番ピン)
| Pin | 信号名 | RP2040機能 | 主な用途・拡張シールドでの役割 |
| :---: | :--- | :--- | :--- |
| **13** | **5V** | 電源入出力 | USB `VBUS` 5V受電、または外部バッテリー昇圧入力 |
| **14** | **GND** | 電源グラウンド | デジタル基準グラウンド（左右対称配置） |
| **15** | **BOOT** | `QSPI_SS` | GNDショートしながら起動でUF2ブートローダー突入 |
| **16** | **GP8** | `UART1_TX` / GPIO8 | 外部無線モジュール（BLE/Wi-Fi/LoRa）への送信 |
| **17** | **GP9** | `UART1_RX` / GPIO9 | 外部通信モジュールからの受信（セカンドシリアル） |
| **18** | **GP20** | GPIO20 (入力) | 拡張シールド操作ボタン：**KEY1 (UP)** |
| **19** | **GP21** | GPIO21 (入力) | 拡張シールド操作ボタン：**KEY2 (DOWN)** |
| **20** | **GP22** | GPIO22 (入力) | 拡張シールド操作ボタン：**KEY3 (ENTER / 決定)** |
| **21** | **SWCLK** | `SWCLK` | オンチップデバッグ用クロック（Picoprobe/J-Link対応） |
| **22** | **SWDIO** | `SWDIO` | オンチップデバッグ用データライン |
| **23** | **GP0** | `RS485_DI` / GPIO0 | 送信信号の外部ロジックアナライザ直接モニタ |
| **24** | **GP1** | `RS485_RO` / GPIO1 | 受信生信号の外部ロジックアナライザ直接モニタ |

## 4. インジケーターLED仕様

本体のみ（PC/スマホなし）での現場診断を可能にするため、**「フルカラーLED 1個 ＋ 通信モニタ単色LED 3個」** を標準搭載する。

### ① フルカラーLED（アドレス指定型RGB LED: 1個）
- **部品選定**: `WS2812B-2020` または `SK6812-EC20`（2.0mm × 2.0mm 超小型SMD）
- **制御ピン**: RP2040の空きGPIO（`GP25` を推奨）1本のみで制御。
- **表示ステータス例**:
  - **青点灯/呼吸**: スマホ / PC と WebSerial 正常接続中
  - **緑点灯**: 通信パケット正常受信（Modbus RTU / DMX フレーム検証OK）
  - **赤点滅**: パケットエラー（CRC不一致、フレームエラー、バス衝突検知）
  - **黄色点灯**: 自動ボーレートスキャン・プロトコル自動判別中
  - **紫呼吸**: ブートローダー / ファームウェア更新モード（UF2書込待機）

### ② 通信＆電源単色LED（3個）
- **`PWR` (電源 / 赤または白)**: 3.3V給電時に点灯。
- **`TX` (送信 / 橙または黄)**: RS-485送信時に点滅。
- **`RX` (受信 / 緑)**: RS-485受信時に点滅。
  - **現場キラーUX**: 端子台に線を挟んだ瞬間、相手機器が生きてパケットを吐いていれば緑LEDが点滅するため、**「線が生きているか死んでいるか」がPCを開く前に1秒で判別可能**。

## 5. 将来の自立型シールド構想（Battery & Display Backpack）

この24P拡張端子を活用することで、以下の拡張シールドを同形サイズ（65×33mm）でスタック可能となる：

1. **ディスプレイ**:
   - 0.96インチ / 1.3インチ I2C OLED（`GP4/GP5` 直結）
   - または 1.14インチ カラーIPS TFT（SPI接続）
2. **操作系**:
   - 3方向タクトスイッチ（UP / DOWN / ENTER：`GP20/GP21/GP22` 直結）
3. **バッテリー＆充電回路**:
   - 3.7V 400〜500mAh 小型LiPoパウチ電池（厚み5〜6mm）
   - TP4056 / TP4054 充電IC ＋ 電源スイッチ ＋ `GP28` 分圧によるバッテリー残量監視
4. **ロガー機能**:
   - microSDスロット（`GP16〜GP19` 直結）による長期通信ログ保存

## 6. 回路設計・アートワーク申し送り事項

1. **BOOTSELピンの保護**:
   - `QSPI_SS` をTHTへ引き出すため、誤接続によるFlash破損防止として直列抵抗（1kΩ）を挿入。
2. **RESETピン**:
   - 10kΩ程度のプルアップ抵抗およびチャタリング防止コンデンサを配置。
3. **完全絶縁（アイソレーション）の境界管理**:
   - 24P THTはすべてRP2040（非絶縁デジタル系）の信号である。
   - 先端のTDA51S485HCおよびスプリング端子台まわりの完全トランス絶縁エリア（ISO_VCC, ISO_GND, A, B）との離隔スリット・沿面距離を厳格に維持すること。
